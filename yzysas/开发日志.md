## 2026-09-26（壅塞物理 + 投影牛顿 + 多物质/不可压分诊）

### 想法 27：壅塞 = 压力的 upwind——从提问到修复的完整闭环

**起点（用户提问）**：出口壅塞后下游节点压力怎么定？接锚点怎么写？
——与温度 upwind 同构的直觉，讨论后精确化三层：

1. **流量公式**：壅塞支 ṁ=ṁ_cap(p0_up) 只看上游，下游压力退场；
   **判据**仍用下游压比（β vs β_crit）——"判断用、计算不用"。
2. **下游节点压力照常**（锚点钉死/下游网络解出），变的只是与上游
   流量的耦合断开——J 里表现 = 特性行对 p_down 列归零（压力 upwind）。
3. **解耦的精确位置**：不是"上下游两个网络"，是瓶颈元件那一条边。

**pipe 动力学壅塞支（缺口补齐）**：ṁ = min(ṁ_Darcy, ṁ_cap)——
cap = gas.choked_flow(A, p0_up, T0_up)（契约方法现成）。min 结构
分支点连续（kink 同 β 夹断族）；判据与白板 choked 同源自洽。
**瓶颈涌现实证**（等面积 A 算例）：流量 0.2025（超物理，需要 Ma=1.3
才通过——白板 choked 本是报警）→ 0.139 = 下游管 cap；p_mid 268170
由"管1 Darcy = 管2 cap"自洽定出；管1 内部亚声速摩擦加速到出口恰
Ma=1（Fanno 图景自组织）。串联双壅塞自相矛盾（cap∝p_up → 连续性
逼 p_mid=p_up → ṁ=0）→ 解自动让下游小容量管独占壅塞。

**双壅塞陷阱实测（用户面积悬殊算例 A1/A2=0.045 触发）**：默认初值
一步精确命中 p*=p_up·A1/A2=13522 Pa（cap 支线性 → 线性化无误差），
J 的 p_mid 列恒零（cond 6e19）→ 冻结 converged=False（诚实）。
冻结点报表迷惑性：连续性全零但特性行残差 5.88e-2（管2 要求倒流
0.0518 vs 正向 0.007009）——"方向不对"与"这里没有解"是同一矛盾
的两种读法。暖启动+独立手算逐位闭合真解（ṁ=cap₁=0.007009，大管
亚声速 Ma=0.078，p_mid=100310 方向正常）。

**投影牛顿（修复）**：全局总压 ≥ min(锚定压力)——被动网络极大值
原理。关键纪律：**约束活在迭代点几何上（初值+线搜索试探点投影），
绝不进残差**（夹残差入口 = 盒内死列 = 换地方卡死）。保险丝：抽出型
MASS_SOURCE（泵抽真空物理可出盒）自动摘除。效果：默认初值 7 轮
收敛 max|F|=2.6e-11（与手算逐位），全量回归零损伤。

**同伦延拓（M2，悬置）**：背压参数化路径（3e5→1e5 缓降，起点=
静止平凡解），贴解曲面走绕开陷阱；对元件零要求（外层调度），
代价 nfev×30。启用判据：容量初值+投影仍失败案例积累后。

**多物质/不可压分诊（同日讨论）**：网络层搬运的 (p0,T0,ṁ) 既不带
物性标签也不带压缩性标签——换热器（不混合）拆两网络+共享 q 耦合；
真混合只有能量方程 cp 约去一处硬锚（远期 L3）；不可压 = LiquidWater
类（incompressible.py 算法体已备：免反解直算，空化=壅塞结构对偶）
+ orifice 一处改动，架构零伤。液体大半契约天然兼容（pipe/AREACHANGE
现成能用），"GasModel 改名 FluidModel"等水真来了再说。

### 想法 17：能量方程三步走与两条设计纪律

**Step a** row_units 三档重构（bool→int：0流量/1压力/2能量）+ Scaling
加 T 列段，空转回归。**Step b** T 进 x（x = [p|T|m]，锚温节点消元）+

**两条纪律（发热元件暴露的）**：
1. 依赖流向的物理量不能在组装期静态登记——旧 _heat_on_node 挂点表
   双倍计账+污染上游（实验实证），必须残差内按解出的符号动态算。
2. 接口报 q 不报 ΔT（q/ṁcp 的 ṁ 在节点方程乘积里被约去，零流量
   代数光滑；ε_q=1e-6 兜温升封顶）。

### 想法 18：port_T_out——温度知识的归属重构

**JUNCTION 元件**（首个三口件）：零压差+绝热完全混合，进料集合按
解出的 ṁ 逐口判断，汇合/分叉一套代码。验证：双温源混合 584.9901K
后分叉两支同温=混合温度（理想分叉不改变温度），分流比=面积比，
三点压力严格相等；booster 环温度场（Step d）待做。

**认知沉淀（教学相长）**：
- 雅可比差分 = 扰动重跑代码，代码路径=链式法则，"写对 F 导数免费"
- 能量 T 子块 = 加权有向拉普拉斯：对角=Σ流出+ε，非对角=-注入量，
  树状下三角/回路对称耦合/死环靠锚温——矩阵形态由拓扑自动决定
- 显式加权公式（T=ΣṁT/Σṁ）是解的性质不是解法：零流量除零+回路
  不动点发散，隐式残差（纯乘加+ε）两者皆无——与项目根基选型同构
- 方程的代数形态决定雅可比品质（层流 √ṁ vs Hagen-Poiseuille）；
  排列/缩放/消元等"摆方程"自由度影响条件数与迭代路径，不影响解

**物性归位**：cp/cv 从 system/scaling 各自手写 γR/(γ-1) 收敛到
fluids/properties.py 单点维护（同源保证），将来变比热只改一处。

### 想法 19：静压口径流量公式——循环依赖与两条防发散纪律

**起因（用户两问）**：① 静参数（Ma/p_s/T_s/V/ρ）按 (p0,T0,ṁ,A) 反算，
存哪？② 篦齿/预旋类公式用 p_s/p_0 算流量，p_s 又依赖 ṁ——鸡生蛋，
且迭代前几步容易发散。

**静参数归属**：不进 Comp——topology 层纪律"只存结构与参数，不含
流动状态"（topology.py 头注释自明），静参数是解完可导出的派生量。
落点 state.py 的 PortState（static_pressure/T、mach_number、choked
字段早备好，补 velocity/density 即齐），反算引擎 fluids.total_to_static
（5 项自验过）。注意区分两个口径：口截面等熵恢复（报表用）≠
元件内部喉道静压（公式用），别共用一个量。

**循环依赖解法选型**：不引新未知量，残差内即时反算
β = p_s/p_01，p_s = total_to_static(p02,T02,ṁ,A_ref).p，隐式回路
ṁ→Ma→p_s→ṁ 在每次残差评估内闭合（二分到机器精度），误差不跨
迭代积累，外层牛顿照常。否掉的替代：不动迭代外层重解（把牛顿的
活手工干，慢且无收敛保障）、未知量改静压（推翻 x 全总压的框架
根基）、总静公式数学互化（Cd 按公式口径标定，换算=重新标定）。

**发散担忧的机理拆解（为什么前几步其实不炸）**：
- 初值处修正恒零：ṁ=0→Ma=0→p_s=p_0，且 p_s−p_0 = O(Ma²) ∝ O(ṁ²)，
  ∂p_s/∂ṁ|₀ = 0——开局几步差分雅可比看到的与已验证的总压口径
  完全一致，静压修正随 Ma² 平滑长出，不是开局就咬人的项；
- 过冲不是爆炸是限幅：ṁ 打到 10 倍物理值→q≥q_max→夹断 Ma=1→
  p_s=0.528·p02 为常数→f₂ 对 ṁ 是斜率 1 的线性函数，牛顿一步拉回
  ṁ_choked。夹断区不是正反馈放大器，是限幅器；
- 数学发散被结构性挡住：线搜索 NaN/Inf→+∞ 拒绝 + α 减半，|x|→∞
  走不通；真实失败模式是 α 触底**停滞**（干净报 converged=False），
  不是飞掉。

**真正的爆点：残差路径 raise**。迭代中间量 p0≤0 时 total_to_static
抛 ValueError（线搜索试探点完全可能踩负压）→ 崩。两条纪律：

1. **残差路径只夹断不 raise**——物理性检查（p0>0/T0>0）在元件
   residual 入口 clamp（max(p0,1) 等，与 orifice 现有 β 夹断同族）；
   total_to_static 的 ValueError 只属于后处理/报表路径。
2. **静压口径默认两段式启动**——第一段 β 用总压口径（现有 orifice，
   光滑已验证）解到收敛，第二段换静压口径 warm-start 再解。成本=
   多一次解算（毫秒级）零新设施；本质=2 步同伦，M2 同伦设施的
   第一个真实用例，将来需要再连续化 β(s)=(1−s)β_total+sβ_static。
   两段失败还能退回总压解+报表标注，永远有底。

**遗留约定（M5 撞上再定）**：A_ref 用元件自身出口口面积起步（元件
局部口径）；环腔节点（多元件共享高流速节点）再升级节点参考面积。

**静参数白板落地（2026-09-25，多轮讨论收敛）**：入口 = 基类
`_static_state(x, ctx, i)` 统一读——优先查白板（assembly 每次
residual(x) 开头对全部有效口**向量化**反算一次，`mach_from_q_arr`
60 轮整组二分，与标量版对拍 ΔMa<1e-8），未命中回退标量现算（单元
测试直调元件仍可用）。纯函数保证 = 白板挂 ctx + 身份键 `x is x`
（差分/线搜索的新数组对象必未命中，同次调用内 assembly 与元件同源）。
座位号 = `_m_idx[i] - _off_m`（发号序红利，零映射）。

**讨论中否掉的两个方案（记教训）**：
1. 元件 residual 里写持久 PortState——试探点污染 + 元件间顺序依赖
   （F 不再是纯函数，差分雅可比根基崩塌）；
2. assembly 全局重建协议——静参数是元件私有量不跨元件共享，全局表
   是为想象规模付今日复杂度（过度工程，自犯自记：给不存在的需求
   设计不便宜的机制，三问过滤器=今天的算例付多少/触发条件真实吗/
   那个未来下它还是正解吗）。

**最终形态**：白板生命周期 = 单次残差评估；持久 PortState 只在解上
填（fill_port_states，报表口径，choked 警告挂此，velocity/density
字段已备）；③ 段元件循环仍逐个 Python 调用——按类型批核（对象→
参数行、分支→np.where 全算加挑选、逐块→scatter）是另一张票，
触发线 = profile 实证 Python 循环占主导（~1000 元件）。

### 想法 20：白板实现 + AREA_CHANGE 元件 + pipe 静密度口径（2026-09-25）

三件事一次落地，互相锁定（白板是地基，pipe 是第一个消费者，
AREA_CHANGE 是面积属于口的模式示范）：

**① 白板（向量化静参数表）**。`system._prime_static` 在每次
residual(x) 第一行：全部有效口（A>0）一次 gather+clamp+整组反算
（`mach_from_q_arr`，60 轮同时二分），闭式出 ma/p/T/rho/v/choked，
写 `ctx._static_table`（身份键 `x is x`）。元件读入口 = 基类
`_static_state(x, ctx, i)`，座位号 = `_m_idx[i] - _off_m`（发号序
与白板序同序，零映射）。**审计实证**（monkeypatch 计数器跑全求解）：
标量 total_to_static/mach_from_q 调用次数 = 0——回退分支是保险丝
不是执行路径（单元测试直调元件时才走）。

实现过程抓到两个 bug 值得记：口级表构建放在 `_anchored_T` 赋值前
（`_build_indices` 的语句顺序本身是依赖关系）；向量化二分零流量口
的 hi 更新条件写错半格（Ma 收敛到 0.5 而非 0）——对拍测试当场抓住。
教训：**两个"语义等价"的实现，等价性是验证出来的不是显然的**。

**② AREA_CHANGE 元件（ElemType=10）**。突扩/突缩，两口面积可不同，
总压损失 ζ·½ρV_min²（A_ref=min(A1,A2) 纯几何量，与流向无关）。
第一个真正消费"面积属于口"模式的元件：损失发生在元件自己的小截面
（局部速度），不碰节点静压。验证 W 算例流量逐位（m=0.05279177，
iters=1）、W2 温度直传（T=649.9997 vs 650，偏差 3e-4 K = ε 正则
设计内效应）。平台手册的突缩 ξ(X) 多项式（分段点 X=0.8 连续性
已验）留作 ζ 自动计算升级。

**③ pipe ρ 口径升级：滞止密度 → 上游口恢复静密度**。旧
`p0/(RT0)` 是 v=0 假想态，流动密度应为 ρs（等熵恢复）。数值影响
真实且不小：A 算例流量 0.2577→0.2043（−20.7%）、S 算例进口压力

### 想法 2：方程组形式选隐式同时求解法

**我的原话**：「我想是 0 = f(m1, m2, p1, p2)」——流量与压力同时作为未知量。

**对比**：节点压力法（显式反解 ṁ）要求元件公式可反解；隐式法元件方程随便写
（经验式/查表/将来 NN 都行），代价是方程组变大（Nint+M）、雅可比稀疏。

**验证**：两管串联 5 元方程组，scipy root 残差 1e-17，独立公式复核一致。
**踩坑**：初版 n_equations=2×n_ports 超定（二口元件 4 方程），正确计数是
**每口 1 未知量配 1 方程**；T0_default 静默回退造成过"假根"，M3 能量方程根治。

### 想法 3：量级差会不会让隐式法不收敛

**问题**：p~1e5 Pa 与 ṁ~1e-2 kg/s 差 7 个量级，牛顿迭代会不会崩？

**结论**：会出问题，但不是隐式的锅，是**未缩放牛顿法的锅**——雅可比列尺度差
7 个量级 → 病态；收敛判据混单位失真；差分步长对小变量是绝对步长。
治法：变量列缩放 + 方程行缩放（M1 缩放层）。scipy lm 内部自带对角缩放，
所以现在侥幸能用——自研求解器时必须自己做。

### 想法 4：静压依赖每次迭代的 tp/tt/mf 怎么办

**问题**：可压缩流动公式要静压，静压又取决于迭代出来的总压/总温/流量。

**结论**：静压是**派生量不是未知量**——元件 residual 内部用"流量参数反解"
局部消元：ṁ = A·p0·√(γ/RT0)·Φ(Ma) 在 Ma∈(0,1] 单调 → 反解 Ma →
链式导出 ps/Ts/v/ρs。阻塞自动处理（Ma 夹在 1，临界压比自然涌现）。
全局-局部两级迭代：全局管 (p0,T0,ṁ)，局部管派生量。
**验证**：`pysas/demo_static_pressure.py`——反解 4 次收敛到 1e-18，
临界压比 0.5283 与理论值一致。将来沉淀为 elements/gastypes.py，
孔板公式可升级为严格静压比形式。

### 想法 5：雅可比怎么来、程序怎么知道 F(x) 里有哪些变量

**结论**：变量表是组装时**指派**的（p_idx_of_node / m_idx_of_port 两张字典），
residual 只认编号；scipy lm 的雅可比是**差分**出来的——逐列加 ε 扰动重算 F。

### 想法 6：residual 其实是个回调函数

**确认**：root 每次求值都完整重算所有元件的 residual（实测 40 次调用，

**init 存跨迭代不变的量（面积/Cd），residual 只算随 x 变的量**；

### 想法 7：用神经网络给初值（热启动）⭐ 待验证

永久回归。

**② 管件层流分支 √ṁ 奇异性**：f=64/Re 隐式依赖 ṁ_guess，
ṁ→0 处 ∂ṁ_ideal/∂ṁ_guess ∝ 1/√ṁ → ∞，差分雅可比爆炸 →
默认零流量初值下阻尼牛顿 α 触底无进展直接失败。收敛的**根**是对的
（f 在根处自洽），病的是通往根的**路径**。
修法：层流段（Re≤2000）改 Hagen-Poiseuille 显式线性律
ṁ = Δp·ρA·D²/(32μL)（对 ṁ_guess 导数恒 0），2000<Re<4000 线性插值，
≥4000 湍流 Swanee-Jain。层流根 w=0、湍流根 w=1，根部自动自洽。
手算核对：Δp=2 Pa 层流管 ṁ=5.067e-4 kg/s（Re=1792）。

**教训**：元件纪律在想法 6 的"残差是 x 的纯函数"之上还要加一条——
**对 x 足够光滑**。凡是"用迭代前流量估值"的项都要检查零流量处导数。

### 想法 11：阻尼 vs 裸牛顿的实测画像（坏初值筛选战果）

**算例 H**（串联双孔板面积比 1.0/0.2，5e5→1e5，工作点 β₁=0.9907
紧贴 √(1−β) 奇异区），坏初值 x0=[p_mid=1e5, ṁ 全 0]：

- 裸牛顿：max|F̃| = 0.79→0.70→1.7→0.78→**14**→0.80 反复跳，
  第 7 步雅可比奇异直接死亡（它把解推进了双壅塞区，压力列变平）。
- 阻尼牛顿：10 步收敛，中途两次回退（α=0.25、0.5），
  末段恢复二阶：2e-2→1.7e-3→9.1e-6→2.9e-10。

**结论**：线搜索的价值不是加速是**保命**——每步残差单调不升，
坏方向被拒绝而不是被放大。

**诚实边界**（两者皆败的算例，也是财富）：x0=[p_mid=0.1, ṁ=0] 时
两孔板同时壅塞 → 压力列全零、J 精确奇异 → 阻尼 it=0 报失败。
这不是缺陷，是局部法的定义域：压力信息在双壅塞区物理不可观，
任何局部法都无解可走——**M2 同伦延拓的动机**（λ=0 线性网络无壅塞）。

### 想法 12：收敛判据从物理量纲改为无量纲

tol=1e-6 的语义从 max|F|<1e-6 kg/s 变为 **max|F̃|<1e-6（无量纲）**，
即计划说的"相对收敛判据"。实测两管算例收敛时 max|F|=5.1e-10 kg/s——
比旧判据更严，却不增加迭代负担（牛顿末段二阶收敛是免费的）。
C++ sas_solver.h 的 tol 注释仍是 max|F(x)| kg/s，移植时需同步。
