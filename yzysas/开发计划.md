# mysas 开发计划

> SAS（二次空气系统）流体网络求解器 pysas 的开发路线。
> 原则：小步验证——每步都有可手算核对的算例，不攒大招。

## 项目定位

Python 原型（算法探索期）→ 成熟后按需移植 C++/LGSAS 插件（产品期）。
核心：`0 = f(m…, p…)` 隐式同时求解法（流量与压力同为未知量），
配合 牛顿 → 离散牛顿 → 同伦延拓 三层联合算法。

## 技术主线（四步，对应原始笔记）

1. 网络拓扑信息定义（JSON → Network 数据结构）        ✅ M0
2. 从拓扑构造非线性方程组（0=f(m,p) 同时求解法）        ✅ M0
3. 非线性方程组线性化与迭代（牛顿→离散牛顿→同伦）       ← M1/M2
4. 线性矩阵求解（小规模稠密 LU，大规模再上稀疏/Krylov） ← 随 M1 顺带

### M1 求解器内核（自研，摆脱 scipy）

- [ ] 缩放层：变量列缩放 S（p_ref/ṁ_ref）+ 方程行缩放 R → 无量纲化，
      解决 p~1e5 与 ṁ~1e-2 相差 7 个量级导致的雅可比病态/判据失真
- [ ] 阻尼牛顿：线搜索 α 回退（残差下降准则），相对收敛判据 max|F̃|<tol
- [ ] 离散牛顿：差分雅可比（缩放后步长自愈），距离-2 染色并行扰动（后期）
- [ ] 验证：与 scipy root 同解；坏初值下阻尼 vs 裸牛顿对比

### M2 全局收敛（同伦延拓）

- [ ] λ 同伦：λ=0 线性阻力网络 → λ=1 真实系统，Δλ 自适应
- [ ] 备用同伦：压比渐增（缓慢开阀）、牛顿同伦
- [ ] 验证：故意烂初值（原牛顿发散的算例）能被同伦救回；λ 轨迹可输出诊断

### M3 能量方程

- [ ] 内部节点 T0 进未知量向量（x = [p0|T0|ṁ]）
- [ ] 节点焓混合方程 Σṁ·h0(T_up) = 0，消除 T0_default 静默回退
- [ ] 验证：串联管网 T0 逐节点演化符合手算；不同边界温度混合算例

### M4 非定常（容腔充排气）

- [ ] 容腔方程 dm/dt = Σṁ，隐式时间推进（每步内嵌 M1 求解器）
- [ ] 时间步自适应（容腔时间常数 τ=ρV/ṁ 刚性）
- [ ] 验证：单容腔充气解析解对比（指数趋近）

### M5 元件库扩充

- [ ] 篦齿封严（经验关联式，params 顺序已定：齿高/齿宽/齿数/间隙）

### M6 工程化

## 约定（开发中反复用到，集中记录）

- 符号：ṁ>0 = 流体经该口**流入**组件；节点连续性 = 挂在该节点所有口的 ṁ 直接求和
- 方程组：x = [内部节点 p0 | 各端口 ṁ]，Nint + M 方阵；元件每口 1 方程（连续+特性按口分摊）
- Python 包不能用 stdlib 模块名（types/inspect/string…）——已踩过
- 每个新元件/新算法必须带手算可核对的最小算例才能合入
