# mysas 开发计划

> SAS（二次空气系统）流体网络求解器 pysas 的开发路线。
> 原则：小步验证——每步都有可手算核对的算例，不攒大招。

## 项目定位

Python 原型（算法探索期）→ 成熟后按需移植 C++/LGSAS 插件（产品期）。
核心：`0 = f(m…, p…)` 隐式同时求解法（流量与压力同为未知量），
配合 牛顿 → 离散牛顿 → 同伦延拓 三层联合算法。

## 技术主线（四步，对应原始笔记）

1. 网络拓扑信息定义（JSON → Network 数据结构）        ✅ M0
2. 从拓扑构造非线性方程组（0=f(m,p) 同时求解法）        ✅ M0
3. 非线性方程组线性化与迭代（牛顿→离散牛顿→同伦）       ✅ M1（同伦 → M2）
4. 线性矩阵求解（小规模稠密 LU，大规模再上稀疏/Krylov） ✅ M1（稠密 LU）

## 约定（开发中反复用到，集中记录）

- 符号：ṁ>0 = 流体经该口**流入**组件；节点连续性 = 挂在该节点所有口的 ṁ 直接求和
- 方程组：x = [全部节点 p0 | 各端口 ṁ]，N + M 方阵（边界元件化后全节点进 x）；
  元件每口 1 方程（连续+特性按口分摊）；边界条件 = 单口元件
  （PRESSURE_BOUNDARY 规定压力/MASS_SOURCE 规定流量，至少 1 个压力边界锚定压力水平）
- 缩放行分档：残差行不再单一流量纲——压力边界行是 Pa，缩放用 1/p_ref
  （row_is_pressure 登记于 assembly，scaling 按行取值；M3 能量行/W、
  M4 容腔行/kg 接入时同样在此分档）
- 初值纪律：压力边界所连节点初值钉 p0_spec，其余取均值——否则起点
  可能落在 beta=1（孔板）或 Dp=0（管）的导数奇异点，牛顿方向失真
- 求解全程在缩放坐标 x̃（scaling 层统一做），收敛判据 = 无量纲 max|F̃|<tol；
  元件作者只需保证残差对 x 是（分段）光滑纯函数，缩放/差分/线搜索不碰元件代码
- 元件残差里凡是"用迭代前流量估值"的项（如 f(Re)），必须检查 ṁ→0 处的
  导数行为——隐式依赖在零流量点的奇异性会炸差分雅可比（M1 踩过）
- Python 包不能用 stdlib 模块名（types/inspect/string…）——已踩过
- 每个新元件/新算法必须带手算可核对的最小算例才能合入
