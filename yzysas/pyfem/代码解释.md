## 0. 全局图景

```
yzysas/pyfem/                    ← 本包（独立于 pysas，可单独复用）
├── fe/                          ← FE 核心（Phase 1，已完成）
│   ├── materials.py               材料随温度插值
│   ├── axisym_heat.py             轴对称稳态热传导（Robin 边界）
│   └── axisym_thermoelastic.py    轴对称热弹性（热应力 + 离心）
├── test_fe.py                   ← 解析解验收（3 用例全绿）
├── test_fe_convergence.py       ← 网格收敛阶验证（≈2.0）
├── demo_fe.py                   ← 全链路演示
└── 开发计划-pyfem.md             计划文档
```

**物理场景**：航空发动机盘/轴类零件 = 轴对称体。取子午面剖面 (r, z)
做 2D 网格，方程里带 2πr 权重，解出的是 3D 轴对称场的精确描述——
这正是 31project 用 gmsh+S3→CAX3+CalculiX 干的事，现在换成
scikit-fem 在同一进程里做。

**求解链**（demo_fe.py 的流程）：

```
材料表 TC11 ──→ ① 稳态热传导 ──→ 节点温度 T
                   (k(T) Picard)      │
                                      ▼
                ② 热弹性 (D(T) Picard + 初应变 αΔT + 离心 ρω²r)
                                      │
                                      ▼
                位移 u、应力 σ 4 分量、von Mises
```

## 1. fe/materials.py — 材料插值

### 设计
- `Material` 类持若干 `(T, value)` 表，按属性名存。
- `__call__(prop, T)` 做线性插值；**表外用端点斜率外推**而不是 clamp
  （np.interp 默认 clamp 会把 773K 以上的 k 钉死在 12.1，外推更物理）。
- 所有方法向量化：输入 ndarray 返回同形数组——FE 积分点求值必需。

### 数据
`TC11` 表逐字迁移自 31project `boundary.txt`（k 5 点 / E 6 点 /
α 4 点 / ρ 常数）。注意 α 表从 373.15K 起，代码里对 <373.15K 用
`np.clip` 到表起点（等价于 CalculiX 对表外温度的行为）。

### 审阅点
- [ ] 外推 vs clamp 的选择你是否认同？
- [ ] `T_ref_alpha = 293.15`（Zero=20°C）写在表里但实际 hardcode 在
      thermoelastic 的 `293.15`——见 §3 的讨论。

## 2. fe/axisym_heat.py — 轴对称稳态热传导

### 控制方程与弱形式

$$\nabla\cdot(k(T)\nabla T) = 0 \quad \text{in } \Omega$$
$$-k\frac{\partial T}{\partial n} = h_j(T - T_{gas,j}) \quad \text{on } \Gamma_j \text{ (FILM)}$$

弱形式（2π 周长并入权 r）：

$$\underbrace{\int_\Omega k(T)\,(\nabla T\cdot\nabla v)\, r\,dr\,dz}_{\text{导热}} + \underbrace{\sum_j \int_{\Gamma_j} h_j\,(T - T_{gas,j})\,v\, r\,ds}_{\text{对流}} = 0$$

对应 CalculiX 的 `*CONDUCTIVITY` + `*FILM`。

### 三个表单（skfem 装饰器）

| 表单 | 代码 | 作用 |
|---|---|---|
| `_conduction` | BilinearForm | 导热刚度 ∫k(∇u·∇v) r —— `w['kT']` 是逐积分点导热率 |
| `_robin_mass` | BilinearForm | Robin 左端 ∫h·u·v r（进刚度矩阵） |
| `_robin_load` | LinearForm | Robin 右端 ∫h·T_gas·v r（进载荷向量） |

**skfem 关键点**：表单里的 `w.x[0]` 是积分点的 r 坐标——轴对称
2πr 权重就靠它进方程，这是 scikit-fem 做轴对称的标准姿势。

### 类 `AxisymHeat`

```python
heat = AxisymHeat(mesh, material=TC11)
heat.add_film("inner", facets, h=500.0, T_gas=700.0)   # 加对流边界
heat.set_dirichlet(dofs, values)                        # 可选温度约束
res = heat.solve()                                      # Picard 迭代
```

**k(T) 非线性处理——Picard（逐次代入）**：
```
repeat:
    A, b = 组装(k(T_old))          ← 温度场进材料
    T_new = solve(A, b)            ← 线性解
until |T_new − T_old| < tol
```
不上真牛顿的理由：k(T) 温和（6.3→12.1，一倍量级），Picard 实测
2-9 步收敛；真牛顿要组装 dk/dT 切线，复杂度不值。**这是有意的
工程取舍**——若将来材料强非线性（比如奥氏体钢相变区）再升级。

### 耦合交换量（Phase 3 的接口，Phase 1 已实现并验证）

| 方法 | 定义 | 物理意义 |
|---|---|---|
| `wall_temps()` | $T_{w,j} = \frac{\int_{\Gamma_j} T\,r\,ds}{\int_{\Gamma_j} r\,ds}$ | r 加权平均壁温——耦合时传给网络侧 WALL_FILM 的 T_w |
| `film_heats()` | $Q_j = 2\pi\int_{\Gamma_j} h_j(T_{gas,j}-T)\,r\,ds$ | 边界总热流（W）——能量守恒对账量（demo 里 Q_in = −Q_out 精确闭合） |

V-FE1 验证的就是这两个量的正确性（对解析解误差 1.4e-4）。

### 审阅点
- [ ] Picard vs 牛顿的取舍
- [ ] wall_temp 用 r 加权（=换热驱动温差意义上的平均）而非面积加权
      ∫2πrTds/∫2πrds——两者其实一致（分子分母的 2π 约掉，r ds 就是
      面积元）。这里明确一下：**就是面积加权平均**。
- [ ] Dirichlet 用 `condense(A, b, x=T_iter, D=...)` 缩聚——skfem
      标准做法，消元不污染矩阵。

## 3. fe/axisym_thermoelastic.py — 轴对称热弹性

### 控制方程

位移 u = (u_r, u_z)，轴对称应变（4 分量）：

$$\varepsilon = \begin{bmatrix} \partial u_r/\partial r \\ \partial u_z/\partial z \\ \color{red}{u_r/r} \\ \partial u_r/\partial z + \partial u_z/\partial r \end{bmatrix}$$

**红色项 εθ = u_r/r 是轴对称的灵魂**——环向应变不靠位移梯度、靠
径向位移本身，这是它和平面应变问题的本质区别。

本构（各向同性 3D 的轴对称块）：

$$D = \begin{bmatrix} D_{11}&D_{12}&D_{12}&0 \\ D_{12}&D_{11}&D_{12}&0 \\ D_{12}&D_{12}&D_{11}&0 \\ 0&0&0&D_{44} \end{bmatrix},\quad D_{11}=\frac{E(1-\nu)}{(1+\nu)(1-2\nu)},\ D_{12}=\frac{E\nu}{(1+\nu)(1-2\nu)},\ D_{44}=\frac{E}{2(1+\nu)}$$

热载荷用**初应变法**：ε_th = α(T)(T−293.15)·[1,1,1,0]，等效节点力
移到右端（`_thermal_load` 表单）。

虚功方程（同样 2πr 权）：

$$\int_\Omega (D(\varepsilon-\varepsilon_{th})):\varepsilon(v)\,r\,dr\,dz = \underbrace{\int_\Omega \rho\omega^2 r\, (e_r\cdot v)\, r\,dr\,dz}_{\text{离心}} + \sum \int t\cdot v\, r\,ds$$

### 代码结构

- `_eps(u, w)`：应变算子——表单共享的核心函数，`u.grad[0,0]`=εr、
  `u[0]/w.x[0]`=εθ。
- `_stiffness` / `_thermal_load` / `_centrifugal` / `_traction`：
  四个表单，组装对应上面方程的各项。
- `AxisymThermoElastic(mesh, material, T_field)`：温度场是**输入**
  （来自 axisym_heat 的解），单向耦合的体现。
- D(T) Picard：同热传导，E(T)/ν(T) 温和，2 步收敛。

### 应力恢复（最容易出错的环节，重点审）

`_stress_recovery()` 逐单元做：

1. **单元常应变**：P1 三角元的位移梯度在单元内是常数，直接用三个
   节点坐标 + 位移差商算（`dN = invA.T @ B` 那段——链法则）。
2. εθ 用形心 r、形心 u_r（P1 的 u_r 在单元内线性，形心值=三点平均）。
3. σ = D(ε − ε_th) 逐单元常值。
4. **节点平均**：节点值 = 相邻单元应力的算术平均（一阶恢复）。

**精度定位**：这够工程云图和量级判断，但节点平均应力精度是 O(h)
——比位移低一阶。V-FE3 旋转盘 4e-3 的误差主要来自这里（检验域
避开孔边应力集中后达标）。**若将来要对标 CalculiX 的节点应力
（外推+磨平），需要升级为应力外推恢复**——记录在案，暂不做
（YAGNI，耦合阶段用不到）。

### 验证里的一个坑（V-FE2 教训）

均匀温升自由膨胀验证：最初约束"单点 u_z=0"，结果 σ ≠ 0
（~1.5 EαΔT）——单点约束在自由膨胀 u_z=αΔT·z 场上引入点力奇异。
改为 **z=0 面 u_z=0**（与解析场在 z=0 处恰好一致）后，
**σ 精确为 0.0 Pa、位移误差 5e-15**。这个用例现在是刚体模态
约束正确性的活检测。

### 审阅点
- [ ] 应力恢复精度 O(h) 够不够你的用途（对标 ccx 留待后续）
- [ ] 293.15（Zero=20°C）hardcode 在两处（`_eps_th_at_qp` 和
      `_stress_recovery`）——应收敛到材料表属性，待重构
- [ ] 离心力用积分点 ρ(T)——材料密度其实是常数，无实质影响

## 4. test_fe.py — 解析解验收（怎么证明代码是对的）

| 用例 | 解析解 | 验证点 | 结果 |
|---|---|---|---|
| **V-FE1** 圆筒双侧 Robin | 串联热阻：R=R_conv1+R_cond+R_conv2，T(r) 对数分布 | Q_inner/Q_outer 对解析热流；4 节点温度对 T(r) | 热流 1.4e-4，温度 7e-7 |
| **V-FE2** 均匀温升自由盘 | u_r=αΔT·r，u_z=αΔT·z，**σ≡0** | max\|σv\|/EαΔT；位移场 | σv=0.0 Pa，位移 5e-15 |
| **V-FE3** 旋转实心盘 | σr=(3+ν)ρω²(b²−r²)/8，σθ=ρω²[(3+ν)b²−(1+3ν)r²]/8 | 域内(0.02~0.19m)节点应力对解析 | σr 4.2e-3，σθ 2.4e-3 |

**方法论**（与 papers/sas-validation-benchmark 同款纪律）：
- 解析解**独立手写**在测试里，不 import 被测代码——防自我验证
- V-FE2 的价值：它是"全链路一致性"测试——本构/应变/初应变/约束
  任何一环错了它都会炸（dN 列序 bug 就是它抓出来的：位移精确但
  应力全错，这种静默错误只有解析解能暴露）
- test_fe_convergence.py：热流误差随网格加密 1.99/2.00/2.00 阶
  收敛（P1 理论值 2）——确认无系统性离散 bug

### 为什么这些用例足够覆盖 Phase 1
- V-FE1 覆盖：Robin 表单、2πr 权、film_heats/wall_temps
- V-FE2 覆盖：热载荷表单、D 矩阵、刚体约束、应力恢复的自平衡
- V-FE3 覆盖：离心表单、应力恢复的非常数场
- k(T)/D(T) Picard 由 demo 覆盖（TC11 真材料 9 步收敛）

## 5. 与 31project / CalculiX 的对照

| CalculiX 概念 | pyfem 对应 | 备注 |
|---|---|---|
| `*FILM, F1, h, T_gas` | `add_film(name, facets, h, T_gas)` | 同一物理，对象化 |
| `*BOUNDARY, dof, T` | `set_dirichlet(dofs, vals)` | |
| `*DLOAD, CENTRIF` | `add_centrifugal(omega2)` | ω² 直接给（ccx 给 ω²） |
| CAX3 轴对称单元 | MeshTri P1 + r 权弱形式 | 数学等价（ccx 内部把 CAX3 展开成 C3D6） |
| `*Expansion, Zero=20` | ε_th = α(T)(T−293.15) | 口径一致 |
| .frd 结果解析 | 直接拿 numpy 数组 | **零文件 IO**——这就是消灭 31project 开销的点 |

**性能对比**（同规模 ~16k 单元）：31project 全链路（划网+4进程+inp
重写+ccx+frd 解析）秒级到十秒级；pyfem 热传导 Picard 全程 <1s，
热弹性 2 步 <1s，且都在内存里。
