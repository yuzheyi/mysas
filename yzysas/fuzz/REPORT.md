## 1. 方法

三层测试，全部只读 pysas、只写 `fuzz/`：

- **A 层 随机拓扑 fuzz（300 例）**：`gen_random.py` + `run_a_fuzz.py`。
  节点 3~12；拓扑 ∈ {chain 链, branch 分支树, merge 汇合(树+含阻冗余边)}；
  面积 1e-8~1e-2 对数均匀；边界压力比 0.05~0.98；总温 300~900 K；元件池
  ORIFICE/PIPE/AREA_CHANGE/BOOSTER/HEATER/JUNCTION/PRESSURE_BOUNDARY/
  MASS_SOURCE（SURROGATE_FLOW 需 npz 模型文件，按任务书"缺文件报错=设计
  行为"排除出随机池，另在 C5 复核）。每例判三件事：不抛未捕获异常 /
  solve 收敛或干净报失败 / 解物理合法（B 层审计）。
  适定性护栏（排除生成器自造病态，详见 `gen_random.py` docstring）：
  ≥2 个 PB 保证压差驱动；零压降元件不成环不成串；JUNCTION 与 HEATER 互斥；
  PB 不与 BOOSTER 同节点；JUNCTION 三口接互异节点。
- **B 层 不变量审计**（`common.py::audit_case`，仅对收敛解）：
  1. 节点连续性 `|Σṁ| < 1e-9·scale`（scale = max(全网 max|ṁ|, 1e-6·m_ref)，
     下限取求解器自身收敛分辨率，防零流量算例拿机器噪声当违反）；
  2. 出料口恒等式 `|ρ·A·v − |ṁ|| < 1e-9`（A=报表几何面积 port.area；
     velocity 为无符号幅值故按 |ṁ| 对照）；
  3. 出料口隐含射流总压 `ps·(T0_jet/Ts)^{γ/(γ−1)} ≤ max(进料口节点总压)
     ×(1+1e-6)`，其中 **T0_jet = Ts·(1+(γ−1)Ma²/2) 由报告状态自洽重构**；
     适用域 = 被动元件（BOOSTER 主动增压不适用）且 |ṁ| ≥ 1e-6·scale；
  4. 节点 T0 ∈ [源温 min, max]（含 HEATER 的网络跳过——加热合法抬温）；
  5. 全场无 NaN/Inf；ps、Ts、ρ（附节点 p0/T0）> 0。
  分级：P0 = 二律违反（任务书指定）/ 收敛解出现 NaN-Inf 或非正静参数；
  P1 = 连续性超求解器自身容差（1e-6·scale）/ 恒等式 > 1e-6 / T0 越界 >1 K；
  P2 = 容差带内弱违反与扩展观察项。
- **C 层 边界酷刑**（`run_c_torture.py`）：C1 背压扫描跨壅塞阈值（两级自适应
  细化到 250/10 Pa，区分"允许的 kink"与"跳变"）、C2 面积比悬殊串联
  1e-2:1e-6、C3 零压差网络、C4 双向流反转、C5 全流量边界适定性断言；
  另含已知非 bug 复核（等面积双壅塞、SURROGATE 缺 npz）。
- **分诊**（对 clean-fail）：`run_restart_diag.py` 五种初值重启（压力抖动/
  源温就近/流量种子/大抖动/平坦化）；`run_scipy_diag.py` 用 scipy
  least_squares（trf/lm，与自研牛顿独立实现）做可解性存在性判定。

### 3.3 P0 机制深潜

**族一：面积盲元件超容量流（A0004/A0257/A0275）**

根因链（以 A0004 为例，复现算例 `fuzz/cases/A0004.json`）：

1. HEATER 元件残差只有"连续性 + 零压降"两条（`heater.py`），无流量-容量
   约束；JUNCTION 同理（零压差三通）。
2. 网络其它元件（AC/孔板特性）把 ṁ=6.98e-3 kg/s 推过 heater 的
   A=5.02e-6 m² 端口——该口声速容量仅 1.14e-3 kg/s（**6.1 倍超限**；
   A0257 达 46.6 倍、A0275 达 57.5 倍）。
3. 出料口报表调度 `port_states → exit_state`：基础实现的 ps=min(腔压, ps_E)
   构造性保证隐含射流总压 ≤ 上游——但**声速钳位支**（ṁ 对应正根穿越 Ma=1）
   按流量自造 ps*=ρ*RT*，越过 ps_E 保险丝 → p0_jet 最高达进料上界的 57 倍。
4. 同一解的进料口白板态 q-clamp（Ma 钳 1）使 ρAv=1.26e-3 ≠ ṁ=6.98e-3
   （EXT2，P2）。

定性：**真 P0**。求解器解出的解满足全部元件方程（残差 <1e-6 收敛判据），
但报表态违反热二律；根子是框架层"元件不申报流量容量时无兜底校验"
（`choke_capacity` 契约只用于缩放自估，未进入任何适定性检查）。
建议方向（不在本次范围）：组装期对"无流量方程元件"的端口做
ṁ ≤ choke_capacity 校验或报表警告。

**族二：exit_state 温度口径（A0199）**

多温网络（含 heater）中壅塞孔板出料平面态由 base 契约以**下游混合节点
T0** 构造声速支（`base.exit_state` 取 `_total_t(x,ctx,j)`），而射流自身
流股 T0 = 上游侧——T0 被抬高 → ps*∝√T0* 与 p0_jet 同步膨胀 → 报表态
违反二律 44%。同族的顺向证据：审计首版用节点 T0 曾把 3 例合法流股误判为
P0（A0061/A0245，管出料应取上游流股 T0），反向用上游 T0 又漏掉本例——
统一用**报告状态自洽重构** T0_jet=Ts(1+(γ−1)Ma²/2) 后，误报全部消失、
真报全部保留。

### 3.4 clean-fail 分诊（258 例）

| 分诊 | 结果 |
| --- | --- |
| 五策略重启合计救活 | **67/258（26%）** |
| 单策略最佳 | R5 平坦化（全部节点 p=max(锚压)）**35 例**，R1 压力抖动 20，R2 源温就近 10（多重计数，救活例可被多策略命中） |

自认 cond~1e16，"实证 4 步收敛"只在精选小算例成立）——平坦化起点让
链路中节点直接站在真解侧。仍死 191 例交 scipy 分诊（§3.5）。

   4.2e-6 kg/s 微流）出口平面 ps 相对不确定度 ~1e-3（χ(M→0) 双精度
   退化），曾使首版审计误报 P0；真解近旁的报表精度无保证。
   复现：`fuzz/cases/A0263.json`。
3. **能量行 ε 正则泄漏**：微流量网络节点 T0 越出源温包络 0.4~0.5 K
   （A0263，量级 ~ε/ṁ），与 `system.py` 注释口径一致但未见文档登记
   报表警告。复现：`fuzz/cases/A0263.json`。
4. **串行链流反转的方向敏感度 0.19%**（C4_04，上游恢复静参换边所致，
   量化见 `fuzz/results/c_torture.json`）。

## 7. 审计口径修订记录（本轮 fuzz 自我校正，供复现者对齐）

任务书公式的实现有三处必须钉死的口径，均为实测误报后修正：

1. **INV2 用 |ṁ|**：`PortState.velocity` 是无符号幅值，出料口带号 ṁ<0，
   直接相减得 2|ṁ| 假误差；
2. **INV3 的 T0 取报告状态自洽重构** `T0_jet=Ts(1+(γ−1)Ma²/2)`：节点混合
   T0（A0061/A0245 误报）与上游流股 T0（A0199 漏报的镜像）都不行；
3. **INV3 的近零流量门槛** `|ṁ| ≥ 1e-6·scale`：死肢端口"出料"分类在
   噪声地板上无数值意义（A0187 误报）。
   另：INV4 对含 HEATER 网络跳过（加热合法抬温）、BOOSTER 不适用 INV3
   （主动增压是参数本职）。

## 9. 总结（≤5 行）

1. 基线 32 项全绿；A 层 300 例随机 fuzz 零崩溃、零未捕获异常，收敛率 14%。
2. 4 例 P0 真发现：面积盲元件（heater/junction）被推入最高 57 倍声速容量
   超限流，击穿 exit_state 热二律保险丝；另 1 例 exit_state 下游混合 T0
   口径缺陷。
3. 干净失败 258 例：26% 可重启救活（平坦化初值最佳，证实 β→1 尖点 +
   ε 死列根因）；scipy 抽样 20 例 0 例可解而 pysas 错过、10 例疑似无解——
   14% 收敛率是参数域解地形属性；C2 极限串联 5/5 证明有解但
   default_guess 够不着。
4. C 层 31 例 0 FAIL：背压跨壅塞连续（220k→215k 历史教训确认已修复）、
   零压差精确零流、反转对称（方向敏感为设计）、适定性断言全部按期触发。
5. 真 bug 一枚：孤立节点组装期不校验、求解期裸 KeyError（C3_07 存证）。
