## 悬置中

### 1. 距离-2 染色差分雅可比（`use_coloring`）

**悬置原因**：M1 逐列差分在小网络上 n+1 次残差评估完全够用，
色数优化的收益要网络大了才显现。`datamodel/solver.py` 里
`use_coloring` 默认已改 False（C++ 规格默认 true，Python 侧如实标注）。

**重启条件**：单次雅可比组装成为 profile 大头，或网络规模 > 几百方程。

**设计要点**（已想好，届时直接写）：
- 稀疏模式从装配层索引推导，不做数值探测：
  连续性行 ↔ 挂在该节点的各口流量列；元件行 ↔ 本元件流量列 + 内部压力列
- 列冲突图 = 两列共享任一行；贪心染色 → 每色一次扰动、整组同时回填
- 验收：染色差分与逐列差分逐元素一致（浮点误差内），残差评估次数
  从 n+1 降到色数

### 2. 解析雅可比（mode=0 纯牛顿）

**悬置原因**：差分雅可比自动包含元件内部派生量的链式贡献
（Re→f、将来的 Ma 反解），1e-8 相对精度对牛顿绰绰有余；
解析导数要每个元件手工链式求导，工作量大且易错。

**重启条件**：大规模网络差分成本成为瓶颈，或某元件差分失准。

**落点**：`ElementModel.jacobian()`（基类已留桩）；
assembly/solver 需约定解析 J 如何进缩放包装（J̃ = R·J·S）。

### 3. 线搜索失败后的兜底（Levenberg-Marquardt / 信任域）

**悬置原因**：M1 验证集里线搜索失败 = 雅可比真奇异
（双孔板同壅塞，压力列信息物理不可观），LM 的对角阻尼救不了
"该列本来就没有信息"的情形——兜底无意义。

**重启条件**：出现"残差不降但 J 非奇异"的真实算例
（那才是线搜索失败本可救的情形）。

**方案备选**：α 触底后转 (J + λD)·dx = −F（λ 从 1e-3·diag 起）；
或直接交给 M2 同伦（更符合现有三层架构）。

### 4. 管件过渡区（Re 2000~4000）的物理

**现状**：层流线性律 ↔ 湍流 Swanee-Jain 按 Re 线性插值 blend，
收敛点自洽（层流根 w=0、湍流根 w=1），过渡带内是工程近似
（真实过渡区本就非唯一）。

**重启条件**：出现工作点恰好落在过渡带、且要与试验对比的算例。

**备选**：Churchill 全 Re 关联式（单公式光滑）——但它保不住
"层流段无 ṁ_guess 依赖"的干净雅可比，采用前需重验坏初值行为。

### 5. m_ref 逐端口细化缩放

**现状（2026-09-29 部分落地）**：make_scaling 已逐口调
choke_capacity（容量契约消费点），None 回退理想口径——cap 口径
从全网统一理想喷嘴细化到真容量（管口 0.1555→0.1319）。但列缩放
S 仍取 max(caps) 单一 m_ref（全网统一刻度），**逐列缩放本体未做**。

若网络面积差 3 个量级以上（大主管 + 小封严齿），小口流量变量
缩放后 ~1e-3，仍可用但不够理想。

**重启条件**：多尺度面积网络出现收敛变慢/判据失真的实证。

**方案**：流量列缩放改为各口自身壅塞容量；行缩放取该行相关口
容量的代表值（几何均值）。注意回归风险：坐标变换不改变根但改变
收敛路径，V1/V2 基准需回归。

### 6. 零压差 kink（管/孔板特征在 Δp=0 处的方向开关）

**现状**：dp≤0 → ṁ_ideal=0，特征在 Δp=0 处 C0 而非 C1；
初值恰好落在 Δp=0（如 p_mid=边界压）时差分跨 kink，导数列失真
（M1 实验里"p_mid=3e5"初值的困难即来源于此，现靠层流线性律缓解）。

**重启条件**：真实算例的迭代路径频繁穿过 Δp≈0。

**方案备选**：光滑方向开关（tanh 型）；或留给 M2 压比渐增同伦自然处理。

### 7. scipy 依赖退场

**现状**：求解器本体（`pysas/solver`）已无 scipy；
test.py / test_solver.py 仍用 scipy root 作对照 oracle
（"与 scipy 同解"本身是 M1 验证项）。

**重启条件**：M6 工程化决定交付形态时（保留对照脚本 or 去依赖打包）。

### 8. 嵌套 min（Darcy vs cap₁）vs cap₂ 的雅可比退化区

**现状**：管件 min(m_darcy, m_cap_fanno) 与下游管 cap 的 min 嵌套，
在两管 cap 相等的平衡点附近双 kink 同时贴界，理论上存在线性化
小步长振荡的退化区（偶阶分岔行为）。

**悬置原因**：双 Fanno 平衡算例 4 轮收敛无异常；理论退化区需要
构造性算例（两管全同参数对称钳位）才能触发，当前验证集未覆盖
也无实证。

**重启条件**：出现对称双钳位算例收敛变慢/振荡的实证。

**预案**：cap 支对 p_mid 的弱依赖（经 Re→f，~0.2 灵敏度）本就
在 J 里（差分自动抓）；若振荡，可给 min 换 smooth-min（softmin
ε~1%流量）——但先等实证，勿预防性光滑化（想法 19 纪律）。

### 9. Darcy 需求曲线的高 Ma 失准（cap 侧 Fanno 已正，需求侧未换）

**现状**：min(Darcy, cap_Fanno) 的 cap 侧已是真摩擦管容量，但
Darcy 侧是不可压公式——ρ 取上游恢复静密度，高 Ma 时（Ma>0.7）
不可压假设低估动量方程的密度变化，需求曲线本身失准：可能高估
亚声速段容量（提前钳位）或该钳不钳（被 cap 兜住）。完备解 =
Fanno 亚声速特性（出口静压匹配 p_down）替换需求曲线。

**悬置原因**：M1 全部手算算例（A/C/S）解点都在 Darcy 曲线上
（低 Ma 或已钳位），无高 Ma 亚声速工作点算例；换特性曲线是
管件残差的物理升级（连带 test_solver 手算同步），影响面大。

**重启条件**：出现高 Ma 亚声速管流算例（Ma_in>0.6 且未壅塞），
或与试验/手册对比需要精细压降。

**已完成的准备**：fanno.py 全套函数（fanno_param/mach_from_fanno/
p0_star_ratio）就是需求侧升级的全部原料——出口静压闭式现成，
届时管件 residual 换特性曲线 + 手算同步即可。

# 一、对 “fanno 不是好办法” 的裁定：部分反驳

**你说对的**：如果 Fanno 要变成“每个压损元件都写一套变体”的先例，那是灾难——突缩不是 Fanno，篦齿不是 Fanno，旋流件更不是。逐元件自研壅塞公式 ×N，物理自由但纪律靠口口相传，`areachange.py` 现在就没有 cap 分支——这就是“自治模式会漏写”的活例。

**我反驳的**：Fanno 本身没有越界——它是**管这种元件的私有物理**（沿程摩擦耗散的容量关联式），就像 Swanee-Jain 是管的摩擦关联式。你要反对的不是 Fanno 的存在，而是**缺少统一契约**让它看起来像“每个元件自己发明壅塞”。病根是架构层缺一个“报值即能力”的容量契约。

# 二、壅塞通用架构：推荐“契约 + 统一形态”

五个候选（逐元件自治 / 基类契约 / 网络层集中钳 / 统一系数 / 查表注册）五维评估后，推荐**方案二骨架 + 方案四形态**——第三个“报值即能力”方法：

```python
class ElementModel:
    def choke_capacity(self, p0_up, t0_up, ctx, j) -> float | None:
        """口 j 作为上游时的壅塞容量 kg/s；None = 无上限（腔/junction）。
        纪律：只依赖 (p0_up,t0_up)+几何；禁读 ṁ_guess（零初值处导数爆炸）。"""
        return None
```

统一**无量纲形态**（元件差异全部折叠进一个系数）：

$$\dot m_{cap} = C_{choke}\cdot A_{ref}\cdot q(1)\cdot\frac{p_0}{\sqrt{T_0}},\qquad C_{choke}\in(0,1]$$

各元件的 $C_{choke}$：

| 元件 | $C_{choke}$ | 物理本质 |
|---|---|---|
| 孔板 | $C_d$（已有，超临界分支内含） | 喉道射流收缩 |
| 管 | $q(M_{in})/q(1)$，$M_{in}=F^{-1}(fL/D)$ | 沿程摩擦（Fanno 退居私有关联式） |
| 突缩 | $C_c\approx0.6{-}0.7$（$=1/(1+\sqrt\zeta)$ 反推或 Idelchik 表） | vena contracta 是真喉道 |
| 突扩 | $\approx 1$（几何最小截面即喉道） | Borda 损失在扩散段 |
| 篦齿 | 经验关联 $C(N,\,c_l/t)$，**末级先临界** | 多孔板串联 + carry-over |
| 预旋喷嘴 | $C_d\cos\alpha$ | 切向速度占用流通能力 |

注意 $\zeta$ 换算的坑：$1/\sqrt{1+\zeta}$ 是“损失折流量系数”（保守下界），物理上限是射流收缩 $C_c=1/(1+\sqrt\zeta)$——ζ=1 时两者差 0.71 vs 0.5，需要你拍板口径（裁决清单 #2）。

**消费点**（框架三处零知识复用）：缩放 `m_ref` 逐口细化（现在退化用理想口径，两管算例自估 0.156 vs 真解 0.258 差 60%——待定 #5 顺手解）、白板 choked 标定、将来的容量初值。min 结构仍活在元件特性内——upwind 裁决（想法 27）零改动。

# 三、腔元件：你的说法**部分对**，两处要修正

> “碰见壅塞，第一个口是上游压力，第二口是腔压力？”

**对的核心**：壅塞支流量只看供流侧滞止态 $(p_{0,up},T_{0,up})$，腔压只进判据 $\beta = p_c/p_{0,up} < \beta_{crit}$，不进流量公式——“判断用下游、计算不用”，与想法 27 完全一致。

**修正一**：不能说“第一个口”。上游/下游按**当前解的状态动态判定**（现状按总压高低选口），腔出流壅塞时**腔自己就是上游**——角色互换自动发生，无需特判。

**修正二**：“腔压力”不是输入，是**节点未知量**。$p_c$ 由该节点连续性平衡（注入−流出=0）解出；壅塞公式只是平衡里的一个“流量项+一条判据不等式”。

三条更干净的结论：

1. **腔 = 节点，不是元件**。它就是“理想集气腔”抽象的原型（大容积、Ma≈0、$p_0\approx p_s$）。有趣的是：平台手册里**没有任何容积腔元件**——所有“腔”都是准定常压比/温比块，印证“腔=节点、储能=M4 再补”的路线。
2. **腔本身没有壅塞容量**。cap 属于喉部几何（孔板喉道、管出口、篦齿末齿），腔无喉部。`choke_capacity` 返回 None 的就是这类。
3. **腔压可以低于壅塞口静压**：上游孔板壅塞时喉部 $p^*$ 与 $p_c$ 不必相等（恢复靠腔内掺混，网络层不写这条方程），唯一约束是判据 $p_c \le p^*$，不满足该支自动解壅塞。

**转动腔的三个效应不要混**（这是 M3 的设计图）：

| 效应 | 本质 | 归属 | 落点 |
|---|---|---|---|
| 风阻温升 | $\Delta T_0 = \sum\tau\omega/(\dot m c_p)$ | **T0 物理** | 节点能量方程功源项（复用 heat_input 机制） |
| 盘泵效应 | $p(r_2)/p(r_1)=\exp[\beta(u_2^2-u_1^2)/2RT]$ | **p0 物理** | 端口半径偏量 $\Delta p_{pump}(r)$，节点仍单 p0 |
| 预旋温降 | $T_{0,rel}=T_0 - UV_\theta/c_p$ | **绝对 T0 不变**，相对 T0 是派生量 | 端口派生量（报表+换热边界 $T_{ad}$），不进方程 |

分层收益：壅塞元件**不需要知道腔在转**——它只消费节点解出的 $(p_0,T_0)$，容量 $q(1)Ap_0/\sqrt{T_0}$ 和判据 $\beta$ 自动跟着变。

# 四、旋流：一处方向勘误 + 四阶段路线

**勘误**（subagent 抓到的，我核实同意）：你之前如果形成过“总 Ma=1 时轴向分量<1，所以壅塞在更高总流量”的印象——**方向反了**。旋流流的壅塞判据是**轴向 Ma=1**（波沿轴向传播），此时总马赫 $>1$ 是允许的；临界流量参数 $q^*$ 随旋流**单调下降**，修正因子 $f\le 1$。一句话：**旋流让壅塞来得更早（容量更低）**。手册旋转孔 $C_{dR}=C_{d0}/\sqrt{1+(u_w/u_m)^2}$ 方向（减）与此互证。

**引入顺序**（依据 = 对已验证核心的扰动半径，不是锚点数量）：

| 阶段 | 内容 | 验证锚点 |
|---|---|---|
| 0 | 回归护栏（V1/V2/陷阱全绿为门禁） | 本地已有 |
| 1 | **温度**：预旋喷嘴自报 $V_{\theta}$、端口派生 $T_{0,rel}$、盘腔 windage 源项 | Geis 2004（**未存档，需补**） |
| 2 | **流量**：接受孔 Cd（Dittmann 多项式）、旋转孔修正、篦齿叠旋流项 | Facchini 2011（本地全文，四锚点） |
| 3 | **壅塞修正**：容量因子 $f(V_\theta/V_z^*)\le1$，判据改轴向 Ma=1 | 解析极限（无旋退化逐位一致为第一判据） |

**网络抽象落点**（关键裁决）：角动量守恒进网络（每节点 +2 未知量）**不推荐**——无旋网络不退化（规模不变只落平凡解）、零流量节点角动量行恒成立会奇异（复制能量方程 ε 正则的教训）、缩放参考值在无旋网=0。推荐**链式输运**：$\beta$ 像 T0 一样沿元件链传递，junction 做质量加权混合，元件只自报 $\beta_{out}$——**无旋时方程组与今天逐位相同，零回归风险**，且平台手册的 KG 元件链就是这个模式（行业先例）。
